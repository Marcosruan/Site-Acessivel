# Aplicação Web — Modelo de Acessibilidade para Sites Educacionais

Protótipo de site educacional desenvolvido como estudo de caso para reduzir barreiras digitais enfrentadas por pessoas com deficiência visual, auditiva, motora e transtornos como TEA e dislexia, seguindo as diretrizes da **WCAG 2.2**.

> Projeto desenvolvido no curso de Bacharelado em Ciência da Computação — UEPB, Campus VII (Patos - PB), 2026.

## 📋 Sobre o projeto

Apenas 2,9% dos sites brasileiros passam em todos os testes de acessibilidade (Big Data Corp / Movimento Web para Todos, 2024). Este projeto propõe um **modelo replicável** de site educacional acessível, integrando tecnologias assistivas digitais ao front-end para atender usuários com:

- Deficiência visual
- Deficiência auditiva
- Deficiência motora
- Transtorno do Espectro Autista (TEA)
- Dislexia

O site é composto por três páginas:

| Página | Descrição |
|---|---|
| **Home** | Hub central de conteúdos e exercícios |
| **Conteúdos** | Textos educativos com imagens ilustrativas |
| **Exercícios** | Questões objetivas (5 alternativas) sobre os conteúdos |

## ♿ Recursos de acessibilidade

- HTML semântico em toda a estruturação das páginas
- Navegação completa via teclado
- Ajuste de contraste de cores
- Controles para aumentar/diminuir o tamanho da fonte
- Descrições textuais (atributos `alt` e equivalentes) para imagens e conteúdo audiovisual, compatíveis com leitores de tela
- Integração com o **VLibras**, tradutor de conteúdo digital para Língua Brasileira de Sinais (Libras)

## 🛠️ Tecnologias utilizadas

- **React** — biblioteca para construção da interface
- **Tailwind CSS** — estilização
- **HTML semântico**
- **Figma** — prototipação de alta fidelidade e identidade visual
- **Whimsical** — wireframes de baixa fidelidade
